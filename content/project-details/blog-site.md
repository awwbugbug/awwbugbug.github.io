# 个人博客网站

这是我使用 **Hugo + PaperMod** 搭建的个人主页与博客网站。

## 主要用途

- 发布博客文章
- 展示个人项目
- 记录学习过程
- 沉淀开发笔记

## 技术栈

- Hugo
- PaperMod
- GitHub
- GitHub Pages

## 当前状态

目前已经完成本地搭建、主题安装、首页优化、项目页建设与基础样式美化。

- 持续优化项目页展示
